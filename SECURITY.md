# Security Policy

## Supported Versions

Calmpal prioritizes the security and privacy of its users. Security patches are applied to the active major release:

| Version | Supported          |
| :------ | :----------------- |
| 4.2.x   | :white_check_mark: |
| < 4.2.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Calmpal, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed description of the vulnerability to:
   - **Email**: [goloubov@gmail.com](mailto:goloubov@gmail.com)
3. Include the following details:
   - Component / screen affected
   - Steps to reproduce the issue
   - Proof of concept or example payload (if applicable)
   - Estimated impact on device privacy or runtime security

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Assessment & Triage**: Within 5 business days.
- **Fix & Public Release**: Handled with priority according to severity.
